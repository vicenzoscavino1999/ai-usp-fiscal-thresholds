# Data availability and reconstruction scope

The scientific reconstruction uses frozen country-level and country/age/sex aggregate extracts. `SOURCE_MANIFEST.json` identifies the current source payload by SHA-256. `provenance_public/FILE_RIGHTS.json` classifies every file in version 2.0.0; FILE_RIGHTS_R5.json preserves the historical r5 inventory. Source terms were reviewed on 2026-11-14 (America/Lima); the statistical snapshots were retrieved in July 2026. This notice adds no observations or revised calibrations.

The data sources, exact frozen queries, retrieval dates, original-download hashes where recorded, transforms and citations are in `provenance_public/SOURCE_CATALOG.json` and the original per-family `metadata.json` files. `provenance_public/PARAMETER_SOURCE_CROSSWALK.json` distinguishes provider identifiers, cited literature and modelling conventions while preserving their original labels. The additional BFJZ files were retrieved on 14 November 2026 from the fixed repository commit recorded in their acquisition manifest; their original licence and README accompany the prepared notices. `THIRD_PARTY_NOTICES.md` describes reuse conditions. `provenance_public/WDI_INDICATOR_LICENSES.json` records the 23 indicator-specific World Bank licence checks. It distinguishes direct ITU coverage rows from WDI-distributed fallback indicators.

## Reproducing the study

Follow `REPRODUCING_JPM_V2.md` to build the pinned Docker environment and run `python reproduce_complete.py --raw-root <survey-originals>`. The runner rebuilds model inputs and calculated outputs from the packaged snapshots; it does not refresh provider APIs. References are comparison targets, not substitutes for generated outputs. `rebuild_inputs.py` invokes the anchor and calibration builders; `rebuild_labor.py` reconstructs the UN SNA labour-share extension. Scenario conventions are documented in the project registries.

The current GMI calculation uses aggregate PIP poverty gaps and WDI conversions. The separate survey_comparators/aggregates files document the manuscript comparison and its arithmetic; the complete runner reconstructs the household-level ENAHO/CASEN cost comparisons from separately supplied original files through surveys/. The `microdata_used` field in the policy-cost reference is false. Optional sources in the manual registry and a SEDLAC status file are metadata, not numerical inputs. IMF fiscal series use the Fiscal Monitor DataMapper aliases recorded in their metadata. PWT is version 10.01; WPP is revision 2024; GRD is version 2025; baseline Ookla speed anchors use 2024 Q4, with 2026 Q1 also retained in the snapshot.

## Recovering source material

For the exact numerical reproduction, obtain the complete frozen package and verify hashes. If a snapshot is missing or altered, stop and recover that version. The source catalogue gives the original endpoint, country/series filters, retrieval date, historical acquisition-script name and available original file hashes. Those acquisition scripts are historical provenance and are **not bundled as runnable download commands in this release**. Current provider downloads may contain revisions and are not guaranteed to match the frozen files. Re-ingestion from live providers is a separately versioned data update, not a repair to this reproduction.

Original GRD workbooks can be requested through the linked provider page; ENAHO/CASEN, SEDLAC payloads, Ookla tiles and boundary files are excluded here. Their absence does not require obtaining them to execute the current aggregate-data reconstruction.

## Reuse

Apply `LICENSE` to code and `LICENSE-DATA` plus the source notices to data. Some source conditions include noncommercial and share-alike requirements. File-level derivative mappings marked `conservative upstream source set` deliberately preserve a superset of relevant notices; they do not assert exact per-cell provenance or grant a single permissive licence over all inputs and outputs. Manuscript publication and its rights are handled separately.

Version 2.0.0 is identified by DOI https://doi.org/10.5281/zenodo.24257720 and the GitHub tag v2.0.0 in https://github.com/vicenzoscavino1999/ai-usp-fiscal-thresholds. The concept DOI https://doi.org/10.5281/zenodo.21348534 links all versions. Complete-run verification and CI reports are generated by the runner; the release assets also preserve the final verification evidence. RELEASE_STATUS.json records the pre-publication source state. Manuscripts and full-text extractions are supplied as the author's accompanying research documents; their copyright is retained and the code and data licences do not extend to them.

At release preparation on 2026-11-15, the INEI download endpoint responded and the official CASEN SPSS endpoint returned HTTP 500. This access probe did not validate complete new downloads. Complete reconstruction is verified using the original frozen files whose SHA-256 hashes are recorded in surveys/INPUT_CONTRACT.json. Obtain those exact versions from the providers; do not substitute a revised file or relax the hash checks. No survey original is redistributed in the repository, source archive or public verification assets.
